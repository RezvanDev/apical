# 🎤🎧 Голосовой финансовый агент (Локальная версия)

Эта версия проекта адаптирована для работы с микрофоном и динамиком на вашем компьютере.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements_local.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
OPENAI_API_KEY=sk-proj-your-openai-key-here
ELEVEN_APIKEY=sk_your-elevenlabs-key-here
OPENAI_PROXY=socks5://your-proxy-here
ELEVEN_PROXY=socks5://your-proxy-here
```

### 3. Запуск
```bash
python local_main.py
```

## 🎯 Что делает система

1. **Слушает микрофон** - записывает вашу речь
2. **Распознает речь** - преобразует в текст (ElevenLabs STT)
3. **Обрабатывает ИИ** - генерирует ответ (GPT-4o)
4. **Синтезирует речь** - создает голосовой ответ (ElevenLabs TTS)
5. **Воспроизводит** - говорит ответ через динамик

## 🔧 Особенности локальной версии

- ✅ **Микрофон + динамик** вместо интеграции с мессенджерами
- ✅ **Умная сегментация речи** - определяет начало/конец фраз
- ✅ **Стриминг ответов** - говорит по мере генерации
- ✅ **Ваш промпт** - финансовый агент Максим
- ✅ **Асинхронная обработка** - быстрая реакция

## 🎤 Управление

- **Говорите в микрофон** для общения с агентом
- **Ctrl+C** для выхода
- Система автоматически определяет паузы в речи

## 📋 Требования

- Python 3.8+
- Микрофон
- Динамики/наушники
- API ключи OpenAI и ElevenLabs
- Прокси (если нужен)

## 🐛 Решение проблем

**Проблема с PyAudio:**
```bash
# macOS
brew install portaudio
pip install pyaudio

# Ubuntu/Debian
sudo apt-get install python3-pyaudio
pip install pyaudio
```

**Проблема с микрофоном:**
- Проверьте разрешения на доступ к микрофону
- Убедитесь, что микрофон работает в других приложениях
